# R005-C — Pairing loss, moment approximation and exact-entry budget
Parent QKV-C; R004. Status advanced mathematical diagnostic; generic repair novelty rejected.
## Operational interface and collision
A residual group of n pairs k_i in R^dk, v_i in R^dv is represented by S=(n,mean k,mean v). In scalar unit-scaled attention C+={(1,1),(-1,-1)}, C-={(1,-1),(-1,1)} share S=(2,0,0) and identical key sets, but query t gives outputs ±tanh(t). Summary-only algorithms cannot distinguish them; equiprobable mean squared error is at least tanh²(t).
This is about key-value pairing lost in this fixed summary, not every compression algorithm. Singleton clusters recover exactly at extra storage; adaptive selection/main-cache state may prevent the collision.
## Exact expansion and finite remainder
Set x=q/sqrt(dk), delta k_i=k_i-mean k, delta v_i=v_i-mean v, u_i=x^T delta k_i,
C_vk=mean(delta v_i delta k_i^T), D=mean exp(u_i).
Since mean u=mean delta v=0,
f(q)=mean v+(C_vk x+R_v)/D,
R_v=mean[(exp(u_i)-1-u_i)delta v_i].
If |u_i|<=eta, ||delta v_i||<=B and m2=mean u_i², Taylor's remainder and Jensen yield
D>=1, 0<=D-1<=exp(eta)m2/2, ||R_v||<=exp(eta)m2 B/2.
Subtract f_hat=mean v+C_vk x:
f-f_hat=[R_v-(D-1)C_vk x]/D,
so ||f-f_hat||<=exp(eta)m2(B+||C_vk x||)/2.
This is a nonasymptotic bound under explicit conditions, not a sharp-query guarantee.
Cluster mass is Z=n exp(x^T mean k)D. Count/centroid uses only n exp(x^T mean k); correcting output direction without D leaves incorrect main/residual mixing.
For the two worlds C_vk=±1, first-order output ±t versus exact ±tanh(t). Error |t-tanh(t)|=t³/3+O(t^5) near zero, and for t>1 first-order output exits the original value convex hull. These stress-test queries are not claimed unit norm.
