## A. A worse observation can be useful through subtraction
Let y=theta*1+epsilon, epsilon~N(0,Sigma), Sigma positive definite. Weights depend on covariance/exogenous metadata, NOT the realized observations. For 1^T w=1, MSE=w^T Sigma w. Classical BLUE is
w*=Sigma^{-1}1/(1^T Sigma^{-1}1).
With z,u independent standard Gaussians, y1=theta+z, y2=theta+2z+u, Sigma=[[1,2],[2,5]].
For w=(p,1-p), R(p)=2(p-1.5)^2+0.5.
Best simplex weights (1,0) have risk 1; equal averaging has risk 2.5; signed weights (1.5,-0.5) have risk 0.5. Thus a noisier observation can help cancel shared noise. More available information itself does not hurt an optimal estimator allowed to ignore it.
This only limits a single convex aggregation of fixed raw values. Two ordinary heads with a=(0.9,0.1), b=(0.3,0.7), followed by output combination 2a-b, exactly implement (1.5,-0.5). All head probabilities are strictly positive and require finite logits.
Differential Transformer already subtracts softmax maps (Eq1). This operator comparison does not claim the full normalized architecture exactly reproduces the scalar estimator.
Decision: park generic signed-correlation cancellation as an architectural novelty claim.
Next task: provide source metadata or independent calibration samples, estimate covariance without hidden theta/noise labels, and test held-out covariance families. Compare best observation, equal/diagonal weights, simplex QP, regularized estimated GLS, two ordinary heads and differential operator under matched information/resources. Report MSE, excess oracle risk, covariance error and cost. Oracle known-covariance results are separate.
Falsifier: those controls solve the task, or benefit needs oracle information. Fixed-linear-weight optimality does not automatically cover observation-adaptive nonlinear weights.

## B. Distribution mismatch can coexist with exact value output
Let p=softmax(l), q_alpha=softmax(alpha*c), alpha>=0. For finite logits:
F(alpha)=KL(p||q_alpha)=constant+log sum_j exp(alpha*c_j)-alpha*E_p[c].
F'=E_q[c]-E_p[c], F''=Var_q(c)>=0.
For nonconstant c, a finite interior optimum uniquely matches E_q[c]=E_p[c]. Thus if V=c, output is EXACTLY preserved even when q!=p. Any value feature affine in c is likewise preserved at an interior optimum.
This is stronger than the identical-V caveat in R003. Attention mismatch is not a sufficient architecture motivation.
Use l=(1,0,-2), c=(1,0,-1). They are not equal up to scalar and shift, so p!=q_alpha for every alpha. The KL optimum is positive and finite. Let a=exp(1), Z=a+1+a^-2, m=(a-a^-2)/Z>0. Then t=exp(alpha)>1 solves (t-t^-1)/(t+1+t^-1)=m.
For V=c, output error is zero. For V=(0,1,0), outputs differ: if middle probabilities were equal and c-means equal, normalization would force all three probabilities equal, contradicting nonproportional centered logits.
Boundary: if E_p[c]<=mean(c), constrained optimum is alpha=0. If c constant, all temperatures give the same uniform q. With finite p and nonconstant c, E_p[c]<max(c), so no infinite optimum when the derivative at zero is negative. Hard-support targets can have an infinite-temperature limit.
A KL oracle is not an output/task-loss oracle. Report separate optima, boundary cases, and visible-token masks; do not silently reuse the R003 logit-L2 oracle.
Next protocol: frozen same-input attention interventions for mechanism isolation, followed only after review by separately matched retraining to assess learnability. Include raw QK, normalized QK, global/query-only scaling and row oracle. Values and output projection are included in utility metrics. Synthetic radial-label tasks are not native-model evidence.
Falsifier: routing residual exists but output/task discrepancy vanishes under appropriate controls.

## C. Detecting query drift cannot reconstruct erased history
Take two possible caches K+ with keys (e2,-e2), K- with keys (-e2,e2), same V=(1,-1). Project each key onto span(e1). The retained projected keys, values, positions and all calibration responses at q=±e1 are identical.
The same future q=e2 requires outputs +a and -a respectively, a=tanh(1). Any algorithm observing only that compressed state and identical future query history returns the same z. Average squared error over equiprobable worlds is z²+a²>=a²≈0.5800; randomization gives E[z²]+a². All original keys/queries are unit norm.
Knowing the new query covariance or rotating the basis cannot identify the lost cache. It can help future entries without recovering old entries.
Scope: no source tokens, residual bits, original KV, hidden-state copy or other side channel. Extra retained information or recomputation changes the interface; this does not show every compressor fails or that real model caches often realize the pair.
R003's online-refresh control must therefore distinguish compressed-only refresh from refresh with access to original data.
Proposed protocol: segment-A calibration/compression, segment-B queries, fixed-cache isolation first; native autoregressive transitions later. Compare static projection, compressed-only refresh, residual cache, mixed/prefix calibration and retained-token recomputation. Measure first-transition output error, recovery over subsequent queries and task loss.
Match ALL retained bytes: KV, residuals, bases, covariance, token IDs, CPU/offload copies. Separately report scratch memory, update/recompute FLOPs, latency and transfers. Full-cache reprojection is an oracle/resource upper bound, not free repair.
ResKV already uses exact plus residual entries under a shared softmax; its Appendix E explicitly identifies residual refresh during generation as future work. KVzip reconstructs context to score importance; this is not guaranteed exact recovery after deletion.
Next question: does any native transition discrepancy remain after fixed-budget residual storage or affordable recomputation? Park novelty if controls solve it or the failure is only adversarial synthetic.
