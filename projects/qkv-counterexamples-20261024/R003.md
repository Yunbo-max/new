## A — Repetition is not necessarily independent evidence
Assume source IDs and multiplicities m_g are visible, copies share score s_g and value v_g, and positions do not change scores. If the task target weights independent sources, y*=sum exp(s_g)v_g / sum exp(s_g). Token attention instead weights each source by m_g exp(s_g).
Two equal-score sources with values +1,-1 and multiplicities 9,1 give 0.8 rather than the source-balanced target 0.
Subtracting log(m_g) from each copy's logit exactly recovers y*. ID deduplication also solves it. If repetition legitimately supplies independent evidence, this target is inappropriate.
ToMe's proportional attention uses +log(size) to preserve multiplicity after merging: opposite objective, same algebra. This is not a new method.
Matched AV is also insufficient as an architecture impossibility argument: uniform pooling of (1,-1) and (0,0) gives zero, but nonlinear value features phi(v)=(v,v²) separate them. Second moments require width; a fixed first-moment interface limitation does not establish a whole-transformer limitation.
Local park: A-known-source-exact-duplicate as a novelty claim.
Next question: with imperfect provenance and partial correlation, are observable cues sufficient to estimate independent evidence beyond deduplication, log-count correction, nonlinear V and existing controls? If generation dependence is unobservable, no guaranteed identification follows from a single observation.
Falsifier: simple controls solve the task, or benefit requires hidden true source labels.

## B — Exact scalar-temperature boundary
For one row with the same visible tokens and no differing bias, raw logits l and normalized logits c satisfy softmax(l)=softmax(alpha c) iff Hl=alpha Hc, H=I-11^T/n.
For nonnegative alpha, alpha*=max(0,(Hc)^T(Hl)/||Hc||²); set alpha*=0 when Hc=0. Residual r=Hl-alpha*Hc. Zero residual permits exact matching; nonzero residual rules it out. Zero temperature is a closed-limit case if strict positivity is required.
Example (common scaling omitted): q=(1,0), keys (1,0),(0,1),(-2,0), yielding l=(1,0,-2), c=(1,0,-1). alpha*=1.5, r=(-1/6,1/3,-1/6), ||r||²=1/6.
This is standard projection/softmax algebra, not a new theorem. A per-row oracle can inspect keys; a query-only predictor may not reproduce it.
Routing difference need not matter: identical V gives identical output. Measure Delta y=(softmax(l)-softmax(alpha c))V and task loss. L2-optimal alpha is not necessarily KL-, output- or task-optimal; compute separate one-dimensional oracles in a future accepted protocol.
Next question: does residual predict native task loss after matched stable training? Frozen-checkpoint insertion alone is confounded by intervention distribution shift.
Controls: raw QK with stable optimization, QKNorm, global and query-only temperature, row-oracle temperatures, matched parameter/FLOP budgets and retraining.
Falsifier: matched training and simple temperature controls remove the task gap. No empirical preference for raw QK is assumed.

## C — Calibration needs query-direction coverage
Fix keys k1=e2,k2=-e2 and scalar V=(1,-1), unit temperature. Project keys onto span(e1), obtaining zero compressed keys.
Calibration q=±e1 gives exactly zero original/compressed logits and output error. Test q=±e2 gives original outputs ±tanh(1), compressed output zero, MSE tanh²(1)≈0.5800. All original queries/keys have unit norm.
This is a fixed-cache projection example. Euclidean key reconstruction error is NOT zero; only calibration score/output errors are zero. It is neither a GQA conversion experiment nor a measured failure of CAGA or SAKI.
With key-error rows E and uncentered second moment M_D=E_D[qq^T], L_D=E_D||Eq||²=tr(E M_D E^T). M_test <= c M_cal in PSD order implies L_test <= c L_cal. In finite dimensions, a finite uniform c for all E exists iff range(M_test) is contained in range(M_cal); its minimal value is the maximal generalized eigenvalue on that range (zero-matrix case handled separately). This is standard quadratic-form reasoning. Output guarantees additionally require value/sensitivity control.
CHASE/CAGA already addresses compatible grouping and aligned sharing. SAKI already studies score distortion, cross-domain and prefix calibration; within-session drift is an explicitly discussed untested extension. None of those generic claims establish novelty.
Next question: after mixed-domain/prefix calibration, regularization and online refresh controls, do native failures still concentrate in poorly covered query directions during within-context transitions?
Falsifier: these simple controls remove the discrepancy at matched storage/rank and accounted update cost.
