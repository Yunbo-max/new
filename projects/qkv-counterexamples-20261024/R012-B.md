# R012-B — GQA output equivalence and radial information bypass

Parent SHA `4683d005f0b01b542961ce0dbef88502c02948ed`; date 2026-10-24. Subjects `QKV-B` and `QKV-B-precision-radial-collision`. All results are exact algebra and executed tiny CPU tensors; **not Qwen3-weight inference**.

## B parent — Ordinary per-query-head temperatures can repair a whole GQA group's output

**Actual information boundary.** For two Q-heads sharing a grouped K/V source, the head outputs after the group's output blocks are `y=sum_h W_h [softmax(s_h)V_h]`. A token-dependent key-radius perturbation changes scores to `s_hj exp(eta a_j)` for every head. The same shared `a_j` must be used by both heads (unlike head-specific fabricated key perturbations). Ordinary Query-only temperatures `alpha_h>0` instead change `s_hj` to `alpha_h*s_hj`. The temperature fit is a *privileged output oracle* if it can observe the perturbed reference output; it is a diagnostic upper bound, NOT a deployable free correction.

**New local theorem.** Let `h = d y_radial/d eta |eta=0` and let columns of G be `g_h = d y_temp/d alpha_h |alpha=1` after the same W_O blocks. The best first-order ordinary temperature repair has residual `||(I−G G^dagger)h||`; only this **post-output** residual, not head KL alone, can motivate another operator. If G spans the particular readout subspace, radial changes can be first-order matched; full finite matching may or may not exist.

**Executed finite witness.** Three visible tokens, two Q-heads and a 2D output: `s1=(1,0,−1)`, `s2=(−.6,.2,.8)`, shared radial ratios `(2,1,.7)`, eta=.15, with fixed 3×2 value maps V1 and V2 specified verbatim in `R012_cpu_checks.py`. No position bias, mask changes or head-specific key factors. The total group output changed by Euclidean norm **0.03759815**. Two regular positive temperatures `alpha1=1.08374402` and `alpha2=1.01679084` made the combined 2D output equal to the perturbed reference to **1.31e−12**. Each head still had positive KL (.0005825, .0002886) between the perturbed attention distribution and its temperature-controlled distribution. The temperature tangent G had rank 2 and condition number 1.297. Therefore both heads' attention mismatch can coexist with *zero GQA-group output mismatch* through an ordinary operator under this privileged same-input readout fit.

**Important qualification.** This toy output is dimension 2; in real Qwen the hidden size is much larger than the number of Q-head temperatures, so G is far from full-row-rank. A globally fitted calibration temperature is weaker than a per-query oracle; match calibration samples, accessible features, latency and scalar count before claiming a real baseline. Later nonlinearity/next-token loss can have further null directions. A nonzero `h_perp` is not sufficient for task loss either.

**Nearest prior methods/simple repair.** QKNorm, QUEST (ICLR 2026), ordinary Q-head temperature, value/output projection adaptation, and matched training. The parent node's new evidence is a discriminating *negative novelty witness*, not a new QKV architecture.

## B precision child — A K rounding collision need not erase V-path information

**Pinned implementation source.** Hugging Face Transformers at immutable SHA `5f4ecf2d9f867a1255131d2461d75793c0cf1db2`, `src/transformers/models/qwen3/modeling_qwen3.py`, applies per-head RMSNorm to Q/K after their projection, then RoPE; V comes from a separate projection **without QK-normalization**, and W_O mixes outputs. Qwen3RMSNorm computes normalized values in FP32 then casts to the input dtype before gain multiplication. With epsilon>0 and nonzero gains, radial information is algebraically invertible over reals; FP16/BF16 casting can destroy it.

**New exact pathway counterexample.** For 128-dimensional BF16 vectors x=ones and 2x, the postcast RMSNorm K is bitwise identical (checked). With an independent ordinary V projection, a two-token head with uniform attention and values `(1,0)` versus `(2,0)` outputs .5 versus 1.0 — **output delta 0.5 despite identical normalized K**. If V is fixed, that same K collision creates zero attention-output difference, meaning a downstream target depending on radius could be unrecoverable through this *restricted head* but not necessarily through the residual stream. Thus per-key K collision is neither proof that the entire model lost radius information nor evidence that it preserves task utility. V and residual access are essential constraints.

**Radial conditioning.** For fixed nonzero direction and `u=||x||²/d`, the log-sensitivity of the postnorm radius to the original radius is `epsilon/(u+epsilon)`, so inverse radial conditioning is `(u+epsilon)/epsilon`. At u/epsilon ratios 1,100,10,000,1,000,000 it is 2,101,10,001,1,000,001. This explains why R011 showed widespread cast collisions at large ratios, but says nothing by itself about natural Qwen activation norms or task importance of the erased component.
