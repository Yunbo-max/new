# R007-C — Long-context dilution and rare high-logit entries
Parent QKV-C. Explicit math and proposed diagnostics, not native evidence.
## Full-cache witness and conditions
Two target pairs (k,v)=(1,1),(-1,-1), plus N distractors (0,0), query t, unit scaling:
f_N(t)=2sinh(t)/(N+2cosh(t)).
Count/mean summary of the target pair is (2,0,0) and outputs zero. Fixed t gives O(1/N) true output: isolated-pair error does NOT imply large long-context error.
For 0<epsilon<1, f>=1-epsilon requires x=exp(t)>=[(1-epsilon)N+sqrt((1-epsilon)^2 N²+4epsilon(2-epsilon))]/(2epsilon), obtained by multiplying the positive denominator and solving epsilon x²-(1-epsilon)Nx-(2-epsilon)>=0. Large N requires approximately log N+log((1-epsilon)/epsilon).
Set t=log N: f=(N²-1)/(2N²+1)->1/2. Mean k/v zero, global cross moment 2/(N+2), first-order output 2log N/(N+2)->0. Meanwhile average logit variance=2(log N)²/(N+2)->0.
Small AVERAGE variance alone cannot control exponential attention error; rare high logits dominate. This does not contradict R005 bound, whose maximum spread eta=log N and exp(eta) grow. Query norm is not uniformly bounded.
This is a forced/global summary witness. Adaptive ResKV/MomentKV may retain targets exactly; do not infer their failure.
