## QKV-A / D1-D3: more adaptive unlabeled calibration can be worse with global zero covariance
Let X be ±1 equiprobable, z,u,epsilon independent centered variance1, theta=X z, D=z+u and y1=theta+epsilon. Allow beta(X) in h=y1+beta(X)D; calibration can see (X,y1,D) with arbitrarily many unlabeled examples, but NO theta target. The true MSE against theta is
  R_x(beta)=E[(epsilon+beta D)^2|X=x]=1+2beta²,
hence beta_R(x)=0 for both contexts. The unlabeled observable conditional output variance is
  J_x(beta)=Var(theta+epsilon+beta D|x)=2+2x beta+2beta²,
hence beta_J(x)=-x/2. J_x improves 2->1.5, yet TRUE R_x degrades 1->1.5. Globally Cov(theta,D)=E_X X=0; a constant beta fitted from unconditional variance gives beta=0 and is harmless. Thus a seemingly richer query-conditional calibrator can be strictly worse EVEN if the global zero-covariance diagnostic passes. This is elementary conditional-regression risk algebra, not a new theorem.
General multivariate condition: for positive definite Sigma_D(x), label-target theta, residual epsilon=y1-theta, and c(x)=Cov(theta,D|x), the observable-variance coefficient satisfies beta_J(x)=beta_R(x)-Sigma_D(x)^(-1)c(x), with true excess MSE c(x)^T Sigma_D(x)^(-1)c(x). The conditional target-covariance restriction, not just global covariance=0, is necessary for equivalence of these two proxy objectives.
Falsifier: actual QKV heads do not estimate a common theta, task-labelled or reward-guided calibration resolves c(x), or ordinary same-budget heads+ridge outperform. ## QKV-A-signal-noise-identifiability / D1-D4: how many actual noisy task labels break the two-world ambiguity?
Extend R008 task worlds, where theta~N(0,T), z,u~N(0,1); observed y1=theta+z, d=z+u and task target theta_s=theta+s*g*d, s uniformly ±1. Unlabeled pairs alone cannot identify s; the oracle β*_s=-1/2+s*g in y1+beta*d. Previous unlabeled minimax midpoint β=-1/2 has excess test MSE 2g².
Now separately grant n calibration task labels L_i=theta_{s,i}+xi_i, xi_i~N(0,sigma_label²); this is DIFFERENT authorization/information and never free. Under known T,g and Gaussian distribution:
 z|d ~N(d/2,1/2), so E[theta|y1,d]=a(y1-d/2), a=T/(T+1/2).
 t_i=L_i-a(y1_i-d_i/2)=s*g*d_i+zeta_i,
 Var(zeta)=sigma_eff²=sigma_label² + (T*0.5)/(T+0.5).
 Conditional on d_i, the optimal equal-prior sign test uses sign(sum_i d_i*t_i). Since sum_i d_i²/2~chi²_n, its EXACT unconditional error probability is
   P_err = F_Student_t_n(-g sqrt(2n)/sigma_eff).
A sign-plug-in estimate β=-1/2+g*sign_est has excess held-out MSE 8g² P_err, while no-label midpoint has 2g². Such labels help this constrained decision rule iff P_err<1/4. At T=9,g=.25,sigma_label²=1: sigma_eff²=1.4736842; n4 P_err=.295748, excess MSE=.147874 vs midpoint .125 (worse), n16 .130554, excess .065277 (better), n64 .011488, excess .005744. n256 P_err=2.55e-6. Checked by SciPy Student-t CDF, no labels or Qwen actually sampled.
This is known hypothesis testing applied to a constructed two-world interface; equal-prior, known distribution and target-defined world s are assumptions. No-label impossibility and label-aided recovery do not conflict.
Simple controls: supervised ridge/GLS, label-only ordinary multihead classifier; a classifier learning s is not a novel attention layer. Native protocol: use same calibration-label count, separate random task worlds and labels, report MSE/regret vs no-label baseline, and control conditional signal leakage.
