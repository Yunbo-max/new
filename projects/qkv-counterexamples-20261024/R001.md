## A — Better concentration can worsen value estimation
Parent QKV-ROOT. Mechanism: routing concentration vs estimation risk.
One query, two fixed scores with gap Delta>0; p=sigmoid(beta*Delta). Values v1=t+e1, v2=t+1+e2, independent zero-mean unit-variance noise, independent of scores. Output y=p*v1+(1-p)*v2.
Expected squared error R(p)=p^2+2(1-p)^2. Minimum at p=2/3 has R=2/3; sharpening to p=1 gives R=1, a 50% relative increase. Threshold beta=log(2)/Delta.
This is a standard bias-variance example, not a new theorem. More generally dy/dbeta=Cov_attention(v,s); d||y-t||^2/dbeta=2(y-t)^T Cov_attention(v,s). Lower attention entropy alone does not specify error direction.
Closest collisions: Integral Transformer explicitly treats over-denoising; DEX modifies output values and attributes differential attention gains to several mechanisms.
Next: establish tasks with identical QK but differing V covariance requiring opposite aggregation; find a deployment-observable signal rather than oracle t.
Falsifier: effect disappears without value noise; or simple temperature/value gating fully explains benefits. Toy existence does not justify architecture novelty.
Status active; full-text novelty and native relevance unresolved.

## B — Normalization can remove key-side information that temperature cannot restore
Parent QKV-ROOT. Mechanism: per-key radial information erasure.
Fixed scalar q=1, V=(1,-1). Inputs K+=(2,1), K-=(1,2), equally likely. Raw outputs are +/-tanh(1/2). Define targets as these outputs. Ideal L2 normalization maps both key sequences to (1,1); output is 0 for any shared or query-only temperature. Average squared error is tanh(1/2)^2, approximately 0.21355.
More generally positive collinear keys r_j*u lose their radius ordering under cosine-only routing.
Scope: fixed interface, no radius leakage through V/residual/positions/upstream recoding. Nonzero normalization epsilon weakens exact invariance. Not an impossibility result for trained Transformers.
Closest collisions: QKNorm; NaLaFormer norm-direction decomposition; query-dependent temperature work. Restoring norms alone is not a credible novelty claim.
Next: test whether key radius predicts task-relevant information after conditioning on direction, position and V, under stable optimization.
Falsifier: conditional radius permutations do not affect held-out quality, or retrained normalized QK matches raw QK at matched capacity.
Status active; no empirical evidence yet.

## C — A function-preserving coordinate change can alter KV sharing error
Parent QKV-ROOT. Mechanism: coordinate-dependent sharing conversion.
Two scalar heads: q1=1,k1=(a,0); q2=-1,k2=(-a,0), a>0; both V=(1,0). Both heads output sigmoid(a). Mean pooling K gives (0,0), so averaged output is 1/2 and squared error tends to 1/4 as a grows.
First apply the legal sign transform (q2,k2)->(-q2,-k2): original logits are unchanged, but both K now agree and pooling has zero error.
For row vectors, Q->QA, K->K*A^(-T) preserves QK^T. With RoPE general A is restricted; -I commutes with rotations and suffices for this example.
This is conversion coordinate dependence, not proof that independent heads are worse, and not a new symmetry theorem. Align-before-average and transformer gauge symmetries are prior-art collision risks.
Next: audit GQA/QCQA/weighted and key-driven grouping for alignment, then define legal sign-flip paired-checkpoint tests with uncompressed logit equivalence checked first.
Falsifier: conversion is invariant, or simple alignment/uptraining removes all effect; no need for elaborate architecture.
Status active; practical magnitude and novelty unresolved.
