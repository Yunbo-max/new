## R006-A — Finite-sample risk WITHOUT theta labels, distinct from R005-A's labeled regression
**D1 Observables and formal objective.** Each calibration example contains ONLY a full pair (y1_i,y2_i), with no theta labels: theta_i~N(0,T), z_i,u_i~N(0,1) independent, y1_i=theta_i+z_i, y2_i=theta_i+2z_i+u_i. Difference d_i=y2_i-y1_i=z_i+u_i. On an independent test pair predict theta by h_beta=y1+beta*d. Observations are i.i.d.; one beta fitted from n training pairs, n>3. The hidden test theta is used for evaluating the *theoretical* loss, not fitting beta.
**D2 Exact derivation.** R(beta)=E[(h_beta-theta)^2]=1+2 beta+2 beta²=1/2+2(beta+1/2)². Oracle beta*=-1/2 (signed combination with weights 1.5,-0.5) gives 0.5, while using y1 only gives 1. No theta labels are available in calibration: estimate beta_hat= -sum(d_i-dbar)(y1_i-y1bar)/sum(d_i-dbar)². Gaussian conditional law E[y1|d]=0.5d and Var(y1|d)=T+0.5. Thus beta_hat has mean -0.5 and Var(beta_hat)=(T+0.5)/[2(n-3)], since S_dd/2~chi-square_(n-1) and E[1/S_dd]=1/[2(n-3)]. Therefore exact independent held-out risk:
    E[R(beta_hat)] = 0.5 + (T+0.5)/(n-3).
Plug-in cancellation helps over y1 alone iff n > 2T+4. Low-sample signed oracle improvement can reverse into actual harm after paying the calibration variance cost. This is elementary regression statistics, not a novel theorem.
**D3 Falsification and ordinary repair.** Shrink beta_tilde=lambda beta_hat, 0<=lambda<=1. Let v=(T+0.5)/[2(n-3)]. Expected risk is 1-lambda+(0.5+2v)lambda², minimized at lambda*=1/(1+4v). This lambda is distribution-oracle information; real equal-information deployment needs cross-validation/regularization. For T=9,n=8, no correction risk 1, plug-in risk 2.4, oracle-shrunk risk 0.895833. A matched shrinkage/ridge/GLS or ordinary multihead projection may fully remove a proposed method advantage. This does NOT conflict with R005-A's different interface with labeled (y1,y2,theta) calibrations and formula (tau²/(b²+tau²))*(n-1)/(n-2); the two sample-complexity thresholds answer different questions.
**D4 Local numerical witness.** Prior private NumPy Monte Carlo used seed 20261024 and 200,000 independent paired-calibration sets per n, T=9: n=8 analytic 2.400000 / measured approx 2.3963; n=24 analytic 0.952381 / measured approx 0.9539; n=32 analytic 0.827586 / measured approx 0.8304; n=128 analytic 0.576000 / measured approx 0.5762. Evaluation uses exact conditional out-of-sample risk per fitted coefficient rather than adding test sampling noise. Not a pretrained-model experiment. R005-A's labeled experiment grid remains proposed/not-run.
**D5 Next falsifier.** On native QKV activations, identify accessible estimates of cross-token noise correlations WITHOUT oracle task labels; compare same-sample regularized GLS and ordinary two-head output mixing with the exact same calibration and inference budget. ## R006-B — When Value has rank two, temperature cannot hide routing mismatch
**D1 Interface.** Fixed three unmasked keys, one query. Let l=(1,0,-2), c=(1,0,-1), p=softmax(l), q_alpha=softmax(alpha*c), alpha>=0. Under no bias and fixed V, compare probability-KL and full head-output error. This is a frozen analytic attention interface; actual positive-epsilon Qwen RMSNorm is radially *injective* in exact arithmetic (correctly noted in R005-B), so this fixture is NOT a native Qwen proof of exact radial erasure.
**D2 Necessary and sufficient test.** delta=p-q has 1^T delta=0. Outputs agree iff V^T delta=0. When V^T restricted to the zero-sum subspace 1-perp has minimum singular value sigma>0, ||V^T delta|| >= sigma||delta||; distribution mismatch cannot disappear in that chosen head interface. For number of tokens n and value dimension d_v<n-1, the restricted map has a nontrivial kernel; equality of outputs despite p!=q is possible. This output-rank condition is ordinary linear algebra, not a new architecture.
**D3 Strict three-token two-value counterexample.** Set m=(0,1,0), V=[c,m] (3x2). The restriction of V^T to 1-perp is invertible. Therefore q_alpha!=p for ALL alpha implies strictly positive squared output error for ALL alpha. Centered l is not a scalar multiple of centered c, so no alpha can produce p. In contrast, with V=c alone KL-optimal alpha matches the output exactly, and with V=m alone a separate value-optimal alpha matches that output exactly (the latter is in R005-B). Thus adding one value feature can turn a completely temperature-repaired scalar fixture into an unavoidable two-feature output mismatch.
**D4 Executed arithmetic (SciPy 1D solvers, double precision).** p=(0.70538451, 0.25949646, 0.03511903); alpha_KL=1.2487219246 with m-output difference 0.04997391594 and two-feature squared output error 0.00249739227. The squared two-output error minimum on alpha>=0 occurs near alpha_out=1.19983304, with residual 0.00214741535 (>0). KL alpha and head-output alpha optimize different objectives. These are CPU toy computations, not a Qwen/WikiText run. Head output can still be repaired by changing value maps, additional heads, downstream projection or matched retraining.
**D5 Prior art and opposing simple controls.** R005-B already derives the output Jacobian and a scalar m witness, and pins Qwen/Qwen3-0.6B config+source. CAOTE (https://arxiv.org/abs/2504.14051) uses value-aware attention output error, and Behavior-Preserving KV Cache Compression (https://arxiv.org/abs/2610.06479) optimizes a downstream behavior reference; SAKI (https://arxiv.org/abs/2608.03228) covers query-statistical score errors. No novelty claim follows from this rank witness alone. Required native test: attention KL vs projected head-output vs next-token KL on held-out Qwen windows, comparing matched global/query temperature and V/WO controls; code, dataset manifest and reviewer remain pending. A simple repair removing native task gap falsifies the intended architecture motivation.

## R006-C — Post-erasure cache recovery has a finite-bit capacity lower bound
**D1 Information boundary.** R004's indistinguishable cache pair has future desired outputs +a or -a, a=tanh(1), after key-sign projection loses their difference. Original KV, source tokens, residuals and their offloaded copies are unavailable. The decoder has compressed cache, future query and at most b auxiliary bits. R005-C studies loss of K-V pairing in mean/centroid compression and the already-known first-order moment repair; the current construction instead quantifies how many bits of *post-deletion* hidden distinctions must have survived in any code to support accurate answers.
**D2 Generalized model.** N independent micro-cache hidden signs S_i uniform +/-1. They produce otherwise identical compressed states; future query reveals index i, target a*S_i. Encoder can retain randomized b-bit message M, decoder sees M and i, NOT original signs or token stream. Let m_i(M)=E[S_i|M]. Bayes-optimal output a*m_i and average squared error = a²[1 - (1/N)sum_i E(m_i²)].
Independence yields sum_i I(S_i;M) <= I(S_1,...,S_N;M) <= b bits. Binary Pinsker gives I(S_i;M) >= E[m_i²]/(2 ln 2), so:
    expected MSE >= a² max{0, 1 - (2 ln 2)b/N}.
Zero error on ALL 2^N possible signs demands b>=N by counting. This is an elementary information bound for a SPECIFIED inaccessible-data interface, not new rate-distortion theory and not a general Transformer impossibility theorem.
**D3 Concrete numerical case and simplest repair.** With N=8 and b=2, a²=0.5800256584; lower bound 0.3790040835. Retaining exact signs for 2 selected micro-caches achieves MSE a²*(1-2/8)=0.4350192438; the gap shows the entropy bound is conservative. For N=1 a SINGLE retained sign bit resolves the original R004 pair exactly; any generic post-erasure "magic recovery" story would mislead.
**D4 Closest implementations and stronger resources.** RestoreKV (https://arxiv.org/html/2608.01247v1) synthesizes restore tokens while full cache remains accessible *before eviction*. ResKV (https://arxiv.org/html/2607.29591v1) and MomentKV (https://arxiv.org/html/2606.01563v1) retain summaries/residual or moments. If original cache, source tokens, replay, residual bits, or offloaded memory is present, the theorem's observation boundary does NOT hold. Those are mandatory matched total-byte and recomputation/latency baselines. "Learned restoration", "add K-V cross-moment" and "aligned KV sharing" cannot be claimed new just from this toy. Actual native transition failure remains unmeasured.
**D5 Falsifier.** At identical total retained bytes including bases, token IDs, residuals and offload, compare compressed-only refresh, residual-bit cache, pre-eviction RestoreKV synthesis, existing MomentKV and exact-token storage on native prefix-query-switch probes. If these established repairs eliminate downstream loss, park the architectural candidate. No implementation or independent design acceptance exists.
