# R015-C — Final-token decision relevance, physical cache occupancy and a non-vacuity lower bound for moment certificates

Date 2026-10-24. Source checkpoint `50b360de8cbb97092fd82ed968dabe113d425272`. Nodes QKV-C parent and QKV-C-unsafe-moment-correction child. Pure CPU / information-theoretic analysis; no trained Qwen model or author code reproduced.

## C parent — target attention is not final predictive behavior

**State/decision interface.** Freeze one attention head and one **linear** two-class readout immediately after its output projection. Removing one target token changes head output by \(p_*(v_*-\mu_B)\), so the true-vs-false logit *margin* changes by \(p_*\Delta\), with \(\Delta=(w_{\mathrm{true}}-w_{\mathrm{false}})^\top W_O(v_*-\mu_B)\). For a baseline margin \(-m<0\), a target flips the preferred class only if \(p_*\Delta>m\). A high-attention target with \(\Delta=0\) contributes no immediate decision change; a negative contrast worsens the correct-class margin. This does not account for nonlinear later layers/long autoregressive trajectories.

**CPU check.** At \(p_*=0.432\), baseline margin −0.2, the positive-class probability is \(\sigma(-0.2)=0.45017\). Contrasts \(\Delta=0,0.25,1,-1\) give positive-class probabilities 0.45017, 0.47702, 0.55774, 0.34706 respectively. A 0.25 contrast does not reverse the winner; a contrast 1 does. This converts R014's post-Value norm identity into a **task-directional** falsifier. Existing Behavior-Preserving KV Cache Compression (arXiv:2610.06479, published Oct 5) already scores pre-eviction changes to full-model next-token KL; Value-Aware Stochastic Eviction (VaSE, arXiv:2606.03928) already protects large Value magnitudes and adds stochastic retention on Qwen3. No output-aware novelty is justified.

**Systems-level independent falsifier.** A logical KV budget does not necessarily represent reclaimed serving memory. If KV is allocated in immutable 16-token physical pages and a page can be reclaimed only when completely empty, retain 1,024 of 16,384 tokens (6.25% logical occupancy). A strategically scattered survivor in each of 1,024 pages uses **all** original pages (100% occupancy), even though most positions are dead. A compacted set uses only 64 pages. In 1,000 seeded uniform *without-replacement* selections of 1,024 survivors, the mean number of occupied original pages was **659.67** (64.42%); standard deviation 9.93. These are simulated placements without token compaction or serving allocator operations, **not vLLM or GPU measurements**. NVIDIA's *KV Cache Compression and Its Infra Problems* (2026) independently identifies this paging failure in production; any claimed memory saving needs measured allocator reclamation/compaction and transfers, in addition to logical byte parity.

**Next native question.** For Qwen3-0.6B and real target retrieval prefixes, benchmark full-cache failure rows, attention mass, projected margin/next-token KL, accurate retained-token counts, *physically reclaimed KV pages* under the chosen serving backend, latency/transfer, and adaptive exact-retention vs VaSE/behavior-preserving baselines. If retrieval is preserved by existing Value-aware methods, or memory is not actually reclaimed, no proposed extra QKV method is justified.

## C moment-safety child — an arbitrarily loose post-eviction certificate without a Value bound

**Information boundary.** Consider one retained key/value pair (0,0) and three evicted scalar keys \((-1,0,1)\). Let two possible evicted Value vectors be \(v^{\pm}=\pm A(1,-2,1)\), with \(A>0\). The compressed state contains evicted count, key sum/mean, value sum/mean and crossmoment \(\sum k_i v_i\) (plus the retained token and future query). Both worlds have **identical** \((n,\sum k,\sum v,\sum kv)=(3,0,0,0)\), irrespective of \(A\). The decoder after irreversible deletion has no source tokens, original KV, offloaded copy, external clipping threshold or certified global Value magnitude bound.

**Exact lower bound.** For query with scalar logit multiplier \(t\ne0\), the full attention outputs are
\[
y_\pm(t)=\pm A{e^{-t}-2+e^t\over 2+e^{-t}+e^t}
 = \pm A{\cosh t-1\over1+\cosh t}.
\]
At \(t=1\) the coefficient is 0.2135522670. CPU checks for \(A=1,10,100\) give full outputs ±0.213552, ±2.135523, ±21.355227 even though the retained moments remain precisely unchanged. ANY estimator based only on those moments returns the same prediction in both worlds; its worst-case absolute error across worlds is at least \(0.2135522670 A\) and average squared error at least \((0.2135522670 A)^2\). **No finite uniform error certificate exists on this unbounded-Value interface**. This strengthens R014's finite-moment indistinguishability by quantifying certificate non-vacuity; it is not a new impossibility theorem beyond known truncated moments / deterministic eviction information bounds.

**Essential caveat: global model constraints can provide bounds.** If the model's actual pre-V normalized hidden states and trained weights provide a valid universal bound \(\|v_i\|\le V_{\max}\), this particular unbounded scaling counterexample is prohibited; a finite but possibly extremely conservative bound can then exist without per-token stored envelopes. Here \(\max|v_i|=2A\), so even the two-world construction demands an error radius at least \(0.1067761335 V_{\max}\). A cheaper certified bound from trained \(W_V\) norms or an explicitly stored maximum may be more useful than a dense moment matrix. Quantization, adaptive queries and output-projected loss require separate treatment.

**Closest prior art and causal falsifiers.** MomentKV v1 (arXiv:2606.01563v1) already stores 1st-order value-key statistics, and R014 separately found a suspected printed Eq35 identity typo; neither proves average benchmark failure. Xie et al. (arXiv:2607.21475v1) have broader deterministic-eviction nonidentifiability with randomized inclusion certificates. WitCert (arXiv:2607.28699) develops cache-*preserving quantization* witnesses, and Certified Sparse Attention (arXiv:2610.24991) retains access to original keys; these are different observation interfaces. A safety innovation would have to yield non-vacuous, correctly priced **post-deletion** certificates in real trained Qwen while beating same-byte exact selection, output clipping, Value norm protection (VaSE), and existing randomized certificates. This synthetic witness is insufficient to claim such a method.
