## QKV-C: The full model itself has a finite fixed-logit planted-retrieval capacity

**D1 — Assumptions.** Single planted target key has score at most `L`; N unrelated background keys for the current query have iid stationary score S with `M=E exp(S)<∞`. Holding L and M constant, background softmax partition `sum exp(S_i) ≈ N M` for large N. Thus even with an unchanged *full* KV cache and perfect target-key alignment,

`p_target ≈ exp(L)/(exp(L)+N M)`,  `N_(p=1/2) ≈ exp(L)/M`.

This concerns attention mass of a single target, not necessarily retrieval task success after other heads or values. It is a distributional approximation, NOT a worst-case bound on all background assignments. Under Q/K RMSNorm with d=128, unit maximum gamma gains and RoPE preserving norms, the key score upper bound is `L=sqrt(128)=11.3137085`. For independent isotropic background directions, `M=_0F_1(;64;32)=1.64558522347`. The half-attention capacity is about `49,792` background keys. At N=8192, 65536, 131072 and 1,048,576, the approximate target mass is `.85872`, `.43174`, `.27530`, `.04533` respectively. These numbers follow directly from the mathematical null; **no pretrained Qwen distribution was measured**.

**D2–D3 — Consequential falsification of a naive compression story.** If a model struggles on a long-context planted fact because its dense-attention target mass is already small, changing a cache summary while trying to preserve dense attention cannot restore lost task signal. The needed remedy may be learned alignment/score calibration, multiple heads, external retrieval or adjusted normalization rather than a better moment cache. Conversely if a target is trained to align and background keys are not isotropic, actual `M` and score max can differ: R012's ~.432 65K toy is **compatible** with this cap, not evidence QKV geometry is missing in native heads.

**D4 — Relevant literature.** *TriAttention* (ICML 2026, `https://proceedings.mlr.press/v306/mao26e.html`) analyzes trained Q/K anisotropy; *Certified Sparse Attention via Perturbed Retrieval* (arXiv:2610.24991v1) gives per-query sparse retrieval bounds but scans all original Keys; *WitCert* (arXiv:2607.28699v1) highlights cross-layer compensation and nonlocal effects. No novelty claim is made for the sigmoid threshold, which is ordinary log-partition analysis.

**D5–D6 — Test.** For each selected actual trained Qwen head, document distribution of target score, background log-partition, masks, gain norms, positional biases and whether full attention is already correct. Then compare full-cache baseline, actual exact-token selection, normalized moment summaries and user task accuracy at the same memory/throughput. If dense attention already lacks the signal, `QKV-C` is a **wrong intervention target** for that task. Native test not launched; `deep_incomplete`.

## QKV-C-unsafe-moment-correction: Identical retained moments can require opposite *infinitesimal* corrections

**D1 — Algorithm and information.** The primary <MomentKV> source (`https://arxiv.org/html/2606.01563v1`) defines eviction scores `alpha_j ||v_j - mean_v - (Scenter k_j)/(ne sqrt(d))||` and post-eviction moments `(ne,sum K,sum V,sum VK^T)`, followed by Eq9/11/12's first-order output. The paper's Appendix B.2 states the correction is always at least as accurate as plain eviction. Prior R008–R010 provide formula-level counterexamples and one identical-statistics pair where FULL correction improves one world but hurts another. The present pair is strictly stronger: **even the sign of the locally safe direction differs**.

**D2 — Explicit 2D keys, scalar values, correct real queries.** Work at d_k=2 with logits `q·k/sqrt(2)`. Let one retained token R have key `k_R=(10sqrt2,0)` and value `v_R=2`; three evicted tokens have keys `(0,-sqrt2),(0,0),(0,+sqrt2)`. The eviction query is `q_old=(1,0)` so R scores 10 and every E token scores 0. Future query is `q_new=(0,1)` so R scores 0 and E scores -1,0,+1. Take the two value vectors across E, with A=8:

`v_E^(+) = (7,-16,9)`, `v_E^(-)=(-9,16,-7)`.

They arise from `v_s = k_scalar + s*A*(1,-2,1)` for k_scalar=(-1,0,1), s∈{+,-}. Both have identical `ne=3`, `sum K=(0,0)`, `sum V=0`, `sum (V K^T)=(0,2sqrt2)`, and identical retained token R. The vector `(1,-2,1)` is simultaneously orthogonal to the constant vector and to k_scalar, so it changes a **second-order association** while keeping all MomentKV retained statistics exactly identical.

**D3 — Actual Algorithm1 selection and numerical outcomes.** Starting with all 4 cache entries and reducing budget to 1 under the same q_old, the paper's residual×attention scoring method evicts all three E tokens (order indices 1,3,2 in + world, 3,1,2 in − world), retaining R in both. Code recomputes centered covariance after every eviction, not only the initial weights. At q_new, the original complete attention output is **+2.5637591600** for the + world and **−0.8530771125** for the − world. Pure eviction predicts `r=2` in both; MomentKV Eq9/11/12 predicts `h=1` in both, using `Zhat_E=3`, `Z_R=1`, `fhat_E=2/3`.

Consider ANY partial step `r+lambda(h-r)=2-lambda`, lambda>0. In the + world the correct output is **greater than 2**, so moving downward must strictly INCREASE squared loss for all lambda>0. In the − world the true output is **less than 2**, and a sufficiently small positive lambda strictly DECREASES squared loss. The sign of the derivative of squared loss at lambda=0 is +1.1275183 vs −5.7061542. No deterministic rule observing only the identical post-eviction MomentKV state and the same future query can tell these worlds apart. In fact **no nonzero scalar output move in either direction** is uniformly safe: moving upward hurts the negative world and moving downward hurts the positive world. Yet if the two hidden worlds are given an equal **prior**, their averaged squared loss is **4.22893670** for plain eviction versus **2.93961875** for full MomentKV correction. Thus a strong *average* result can coexist with failure of a *pointwise* universal guarantee; prior assignment changes the objective.

One can derive the exact threshold for this sign reversal: with A> `(2(2+2cosh1)−(2+2sinh1))/(2cosh1−2)≈5.360088` the positive world has true y>r. Our chosen A=8 is inside this open regime, not a numerically fragile equality.

**D4 — Certificate and non-novelty boundary.** A strictly positive uniformly helpful update would require a positive lower bound on the directional quantity `<h-r, y_true-r>` over ALL full caches compatible with retained information. Because the + world makes it strictly NEGATIVE, no such bound exists for this compressed state. The R012 conservative `lambda_safe=max(0,1-B/||h-r||)` must therefore abstain here if B is valid; storing stronger metadata/retaining exact tokens/randomizing selection changes the interface and storage budget. This is a concrete MomentKV-instance refinement of a general deterministic-eviction nonidentifiability result already known from Peng Xie's arXiv:2607.21475v1. **We are NOT claiming a new universal theorem or practical novel cache method.**
