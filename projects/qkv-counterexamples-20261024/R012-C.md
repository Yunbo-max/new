## C parent — Query-conditioned retrieval requires the background log partition, not the tail of one random key

**Operational setup.** One deliberately aligned target key has score `s*`; N unrelated background keys have iid score S for a fixed query. Suppose `M=E exp(S)` is finite, and the background score distribution remains fixed with N. By law of large numbers, `N^-1 sum exp(S_i) -> M`; the target's softmax mass behaves as

`p_target ≈ exp(s*)/[exp(s*)+N M] = sigmoid(s*−log N−log M)`.

The transition to appreciable attention mass therefore occurs near `s* = log N+log M`, **not** simply logN. A random-key spherical-cap tail bound from R010 conditions on the target key being random and uncorrelated with the query, which is false when retrieval deliberately aligns the target with a query. This is textbook concentration/softmax algebra, not a new attention mechanism.

**Exact isotropic-sphere benchmark.** With unit-gain per-head RMS-normalized Q/K in d dimensions and independent uniform background directions, Q/K have Euclidean norm sqrt(d), `S=sqrt(d)*U_1`, where U_1 is the first coordinate of a uniform direction. Its score moment-generating function at 1 is

`M = _0F_1(; d/2; d/4)`.

At d=128, M=1.6455852235 (`log M=.49809608`). With one perfectly aligned target key `s*=sqrt(128)=11.3137085` and N=65,536 random background keys, transition threshold is **11.588451**, and the finite-N partition approximation predicts target mass **0.4317432**. 64 actual synthetic background draws (independent Gaussian coordinate + chi-square rest) measured mean **0.4314947**, standard deviation .0012056. R011's ~43% planted-key finding is thus quantitatively explained; it is **not** counterevidence to the old random-key tail under that tail's own assumptions. A learned or position-biased background will change M, and exact real Qwen logits/key retention must be measured.

**Strongest controls/nearest works.** Qwen3's RoPE, learned gamma and pre-RoPE Q/K anisotropy, TriAttention, query-aware eviction/importance selection, and recent sparse attention certificates. Query-conditioned large key mass does not imply a learned model's compressed output changes: compare after V/W_O, whether an adaptive baseline retains that key and all stored bytes. The source study `yyfenghuang/qwen3-qk-norm` reports trained Qwen3-0.6B capture experiments, but its raw `results/qk_stats.json` is not committed and was **not independently rerun**. Full-Qwen native logit measurements remain a blocker.

## C child — Damped certification strictly generalizes full-correction certification

**Information and exact theorem.** Let r be the plain-eviction output and h the moment-corrected estimate, d=h−r. Suppose an **honest runtime-computable bound** `||y_true−h||<=B` is available using information retained BEFORE deleting the original KV (including value/key-norm envelopes whose bytes are explicitly charged). Write e=y_true−h. Choose a scalar correction `r+lambda*d` with lambda>=0. The exact squared-error improvement over no correction is

`||y_true−r||² − ||y_true−(r+lambda*d)||²`
`=2lambda||d||² + 2lambda<d,e> − lambda²||d||²`
`>= lambda[(2−lambda)||d||²−2||d||B]`.

For lambda=1 (full correction), strict guarantee requires B<||d||/2 (the R009 rule). But when **B<||d||** there always exists a positive partially corrected lambda with guaranteed improvement. The coefficient maximizing this *lower bound* is

`lambda_safe = max(0, 1−B/||d||)` (set lambda=0 when d=0),

and its guaranteed squared-error improvement lower bound is `(max(||d||−B,0))²`. The result is a standard robust one-dimensional quadratic shrinker, NOT a new certificate technique. Importantly, a failed certificate is abstention, never evidence correction is harmful.

**Executed CPU test and information caveat.** Reuse exactly R009/R010's declared scalar synthetic group: retained `(score=0,value=b)`, evicted scores `±t`, values `±1`, t~Uniform(0,2), b~N(0,1), n=20,000 seed=20261024. The same conservative Jensen/Taylor B from R009 was used. The full-correction gate certified **18.53%**; the damped safe gate certified **24.91%**; measured false certifications 0 in this synthetic sample, consistent with the mathematical bound. Full proposed correction was actually helpful in 86.255% of the draws, while damped correction only acts on its certified subset. The gap signals **extreme conservativeness**, not automatic usefulness on real models.

The proof needs a truly valid B calculated from *stored information*. In this special symmetric toy group, the code uses the true t to evaluate an envelope — that value must be treated as an extra retained maximum-score/key-norm bound, **not** an uncharged post-deletion oracle. Any general implementation must actually store or upper-bound it without original discarded KV and count all bytes, CPU/GPU offload, transfers and recomputations. If the metadata costs more than storing some exact tokens, the method may have no value.

**Prior-art and strongest repairs.** Xie (2026) already develops randomized-design certificates and proves deterministic deletion nonidentifiability: https://arxiv.org/html/2607.21475v1 . *Certified Sparse Attention via Perturbed Retrieval* (arXiv:2610.24991, submitted 18 Oct 2026) already provides stronger per-query probabilistic certificates but keeps/scans the original keys, unlike irreversible deletion. *MomentKV* v1 https://arxiv.org/html/2606.01563v1 Eq9/11/12 and Appendix B.2 already proposes moment correction and makes an unconditional claim refuted by prior small-cache witnesses. Also compare plain eviction, exact-token retention, value clipping, reuse/CPU offload and all standard abstention/soft shrinkage. Generic certified damping is not a defensible novelty claim without a distinct access/cost or task result.
