## B parent: softmax temperature and Value-projected indistinguishability

For original logits s and a key-radius perturbation giving new logits ell_j=s_j exp(eta a_j), a positive scalar temperature alpha reproduces the TWO-token distribution exactly iff ell1-ell2=alpha(s1-s2) and alpha>=0. When the original gap is nonzero and the sign is preserved, this is an exact conventional repair, not an architectural novelty. At s=(1,-1), radii=(2,.7), eta=.3, alpha=1.064833927568 and the two attention probability vectors agree to numerical precision.

With THREE tokens s=(1,0,-1), radii=(2,1,.7), eta=.3, optimal scalar-temperature KL remains 0.0017010841 (strictly positive). However taking a nonconstant value feature V=s, the KL optimality condition E_q[s]=E_p[s] makes the head output exactly agree. The computed nonconstant-value output difference is ~2e-14. This is basic exponential-family moment matching: nonzero KL does not establish even head-output error, much less next-token/task loss. Stronger controls are value/readout projection, head aggregation, position and mask preservation, query temperature fit, and matched retraining.

**Next:** inspect actual Qwen logits, the V and WO operators, and next-token NLL; contrast output-level error with score Fisher residual. **Falsifier:** scalar/full-head simple alternatives explain or remove the native task gap.

## B child: quantization of near-erased scale is not automatically harmful

Pinned Qwen3 model code at `huggingface/transformers` commit `5f4ecf2d9f867a1255131d2461d75793c0cf1db2` casts Q/K head inputs to FP32 for RMS, casts normalized values back to the input dtype, multiplies learned gain, and applies RoPE. In exact reals with epsilon>0 and nonzero gains, the operator is injective. Let u=||x||²/d, scaling input by a=2 gives

\[ \frac{F(2x)}{F(x)}=2\sqrt{\frac{u+\epsilon}{4u+\epsilon}}=1+\frac{3\epsilon}{8u}+O((\epsilon/u)^2),\quad u\gg\epsilon. \]

At u=1, eps=1e-6, this ideal contrast is just 3.749998e-7. With only one key logit originally <=10 in magnitude, the maximum score change is 3.75e-6. If all values have norm <=1, the induced single-head output difference is <=2 tanh(|delta_score|/4) <=1.875e-6, using the maximum shift of a logistic mixing coefficient. This is a one-key, fixed-head bound; it does NOT upper-bound accumulated language-model errors across layers.

The local source-order CPU fixture found input x=ones and 2x collapse to identical BF16/FP16 normalized 128-d vectors but not FP32. The physically different low-norm regime u≈epsilon has relative scaling effect 0.264911 and does NOT collapse in that constant-vector test. At u/epsilon=1000 BF16 but not FP16 collides; at u/epsilon=1e6 both collide. Actual pretrained activations' u distribution, learned gamma, kernels, masks, V/WO and task error are unmeasured; a numerical collision is not itself a learned feature or a model failure.
