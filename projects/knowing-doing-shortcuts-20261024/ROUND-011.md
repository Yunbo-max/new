## B2 — Found and repaired a genuine causal evidence-gate error

Read local R010 original `action_value_gate.py`: forced rows were accepted based only on `arm` labels and the string `forcing='action_only'`. Injected deliberately contradictory records where **forced-call had executed skip**; R010 `admit()` returned a nonempty valid group. This is an actual code-check result, not a stochastic model phenomenon. Fixed R011 `action_gate_v2.py` now requires requested arm = actual executed action, nonempty tool-call receipt/trace for executed calls, no call receipt on skips, identical action prestate/provenance, unchanged continuation-policy hash, duplicate-seed rejection, fixed analysis split and robust nonnegative costs. Confirmatory regret lower bound uses one-sided union Hoeffding over three probabilities per state, not a single pair of outcomes. **17/17 stdlib regression tests passed**, including cases missing from old tests. Caveat: these are consistency checks only; a dishonest or faulty logger could still forge receipt fields and hashes. Next actor independent external reviewer to validate actual instrumented runtime before native Qwen tests. Closest prior art CTA/CITA/CSI.

## B4 — Real conditional evidence for effort analysis, without causality

The pooled failed-run token gap is +1188.72, but the mixed model×task conditional gap is −245.39, with 95% bootstrap interval [−859,+425]. More tokens could reflect difficult tasks or attempted recovery, while fewer tokens within a group could reflect failures ending early. No externally randomized compute budgets, so neither is an estimate of effect of assigning additional reasoning. COLM CATS, compute-bandit and strong fixed-budget policies are the required next baselines. Next test: task-matched randomized budgets and held-out success, measuring truncation and actual token cost separately. B4 remains active/deep_incomplete.
