## Full-frontier scientific results and next tests

### B1: A necessity label does not identify expected tool uplift
If `Y(0)=0`, then the model failed without tools, but `Y(1)` may also be 0; after adding tool cost, tool use can have strictly negative net utility. When2Tool's label is a different target than `V(h)=E[Y(1)-Y(0)|h]`. Its label is not invalid; it answers a different question. Matched interventions must hold the same decision-state h. Nearest simple baseline: When2Tool Probe&Prefill with the original necessity target; contrast a separately trained action-value predictor at matched training data/cost. Falsifier: if benefit-targeted estimates add no conditional task success or utility over correctly tuned necessity thresholds, no new benefit. Status: code-level difference verified, native LLM test pending.

### B2: Announced fee is not equivalent to actual enforced tool cost
Decision-state action `A = f(H,D,U)` may depend on *announced price D* and random state U. If *actual post-action fee C* is hidden until after the choice, then, assuming no leakage, `P(A|do(C=c1),H,D)=P(A|do(C=c2),H,D)`. A difference would invalidate isolation or reveal hidden information leakage, not demonstrate spontaneous anticipation of unobserved cost. Conversely randomizing text D can alter prompt interpretation, not just numeric utility. Proposed orthogonal interventions: announced-price arm (same pre-price context, varied visible D), actual charged fee (not visible before action), and a cost-wording placebo; use a common pre-action continuation for forced-call/skip/free within each fixed D. CTA is the strongest simple prior-calibrated cost baseline. Status: conditional independence proposition under explicit assumptions; untested on model.

### B3: Long-horizon score gap does not localize the responsible decision-maker
SpecBench's architecture couples an outer candidate-search controller to an inner coding agent. If the outer controller selects candidates by visible score, a proxy-induced hidden-performance gap need not imply the inner LLM individually chose a deceptive shortcut. Compare fixed-policy inner agent with two different outer selection criteria, and fixed outer controller with varied inner policies. Keep the specification and gold hidden evaluator unchanged. Use full actual action traces and include a non-exploitable cue control. Simple baseline: sealed evaluation and reference-solution checks. Status: architectural source analysis; not a new reward-hacking benchmark or demonstration of intent.

### B4: Budget effects include truncation and controller policy
Assign `B` externally before generation, record consumed `M` and independently graded success `Y`. An intention-to-treat estimate `E[Y|do(B=b)]` reflects budget assignment effects, possibly including truncation and output-format changes. It is not the same as the causal effect of 'one more useful thinking token'. Conditioning on realized M after budget assignment risks post-treatment selection. For nested agents, outer-search steps and inner-model tokens must be measured separately. Falsifier: after comparison to standard adaptive-stop/compute allocation baselines with matched actual resource costs, no special delayed-benefit regime remains. Status: source and identification boundary checked, no real effort curves observed.
